# مستند | نظام الأرشفة الأكاديمي الذكي (Smart Archive)

نظام متطور لإدارة وأرشفة دفاتر الاختبارات الجامعية باستخدام تقنيات الذكاء الاصطناعي لاستخراج البيانات والتحقق من صحتها آلياً.

## المميزات الأساسية
- **الأرشفة الذكية:** استخراج بيانات الطالب (الاسم، رقم القيد) والمادة من غلاف الدفتر آلياً.
- **التحقق المتقاطع:** مقارنة البيانات المستخرجة من الورقة مع البيانات المسجلة في النظام لمنع أخطاء الأرشفة.
- **المعاينة المدمجة:** استعراض ملفات PDF والصور داخل النظام دون الحاجة للتحميل.
- **إدارة كاملة:** صلاحيات للمديرين والموظفين، إدارة كليات، أقسام، ومواد دراسية.
- **سجل العمليات:** تتبع شامل لكافة الحركات داخل النظام لضمان الأمان والشفافية.

## المتطلبات التقنية (Prerequisites)
- **Node.js:** الإصدار 18 أو أحدث.
- **NPM:** مدير الحزم الخاص بـ Node.js.

## طريقة التشغيل محلياً (Installation)

1. بعد فك الضغط عن الملف، افتح المجلد في "Terminal" أو "Command Prompt".
2. قم بتثبيت المكتبات اللازمة:
   ```bash
   npm install
   ```
3. قم بإنشاء ملف باسم `.env.local` في المجلد الرئيسي وأضف فيه مفاتيح الربط (سيتم تزويدك بها):
   ```env
   OPENROUTER_API_KEY=your_api_key_here
   ```
4. ابدأ تشغيل النظام في وضع التطوير:
   ```bash
   npm run dev
   ```
5. افتح المتصفح على الرابط: `http://localhost:3000`

## مخطط قاعدة البيانات (Firestore Schema)

### 1. المستخدمين (users)
- `name`, `username`, `password`, `role` (manager/employee), `status`.

### 2. الهيكلية الأكاديمية
- **Colleges:** `name`, `code`.
- **Departments:** `nameAr`, `code`, `collegeId`.
- **Subjects:** `nameAr`, `level`, `term`, `departmentId`.

### 3. الطلاب (students)
- `name`, `regId`, `level`, `departmentId`, `academicYear`, `admissionType`.

### 4. الأرشيف (archives)
- `studentRegId`, `file_data` (Base64), `thumbnail`, `subjectId`, `uploadedAt`.
